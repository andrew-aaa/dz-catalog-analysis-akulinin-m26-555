# Анализ каталога фильмов

Проект для анализа каталога фильмов.

## Требования

- Python >= 3.13
- uv (менеджер пакетов)

## Установка

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd dz-catalog-analysis-akulinin-m26-555

# Установить зависимости
uv sync
```

## Использование

```bash
# Запустить анализ каталога
uv run catalog_analysis.py

# Проверить код стилем
uv run ruff check .
```

## Функционал

Проект включает функции для:
- Расчёта среднего рейтинга и возраста фильмов
- Сортировки и фильтрации по рейтингу, жанрам, актёрам
- Форматирования отчётов
- Работы с множествами, словарями, генераторами
